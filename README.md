# MYGENIUS — личный музыкальный архив

Публичный тёмный сайт с текстами, альбомами и авторскими аннотациями. Управление контентом доступно только аккаунту владельца благодаря Supabase Auth + Row Level Security (RLS).

## Что уже реализовано
- Публичная главная страница, поиск по трекам и каталог релизов.
- Страница песни с текстом и блоком аннотаций.
- Вход владельца по email и паролю.
- Админ-панель: добавление, изменение и удаление треков и альбомов.
- Добавление аннотаций к песням.
- Адаптивный тёмный интерфейс с лаймовыми акцентами.

## 1. Создай базу данных
1. Зарегистрируйся на https://supabase.com/ и создай проект (Free).
2. В проекте открой **Authentication → Users → Add user**. Создай пользователя с email и надёжным паролем. Отключи публичную регистрацию: **Authentication → Settings → Allow new users to sign up = OFF** (если настройка доступна в твоём тарифе/интерфейсе).
3. Скопируй UUID созданного пользователя.
4. Открой **SQL Editor**, файл `supabase/schema.sql` и замени каждое `ADMIN_USER_UUID` на UUID своего пользователя. Выполни SQL.
5. Открой **Project Settings → API** и скопируй Project URL и `anon` / publishable key.

## 2. Подключи проект локально
1. Установи Node.js LTS.
2. Распакуй архив и открой папку проекта в терминале.
3. Создай файл `.env` на основе `.env.example`.
4. Заполни `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Выполни:
   ```bash
   npm install
   npm run dev
   ```
6. Для проверки production-сборки: `npm run build`.

**Важно:** в браузер можно помещать только Supabase anon/publishable key. Никогда не добавляй `service_role` key в `.env` фронтенда или GitHub.

## 3. Бесплатная публикация
Рекомендуемый вариант — **Cloudflare Pages**:
1. Создай GitHub-репозиторий и загрузи туда файлы проекта.
2. В Cloudflare Pages выбери подключение Git-репозитория.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Build output directory: `dist`.
6. В Settings → Environment variables добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` для Production.
7. Запусти Deploy. Cloudflare выдаст бесплатный адрес вида `project.pages.dev`.

Также можно использовать Vercel: импортировать репозиторий, выбрать Vite, build `npm run build`, output `dist`, добавить те же две переменные окружения.

## Безопасность
- Публичная часть может читать записи.
- Все операции записи разрешены только одному UUID через RLS.
- Админ-кнопки в интерфейсе — не граница безопасности; настоящая защита находится в PostgreSQL policies.
- Не включай публичную регистрацию после создания своего аккаунта.
- Не публикуй пароль, service role key или личные токены.
- Если ошибочно оставишь `ADMIN_USER_UUID` в SQL, запись будет заблокирована. Это безопасное поведение: нужно заменить placeholder на UUID и повторно создать политики.

## Текущие ограничения стартовой версии
- Обложки задаются URL-адресом; загрузка файлов в Storage подготовлена на уровне базы, интерфейс загрузки можно добавить следующим этапом.
- Встроенного проигрывателя аудио пока нет.
- Аннотации добавляются отдельным блоком по текстовой цитате; интерактивное выделение строк прямо в тексте — следующий этап.
- Это стартовый проект, перед публичным запуском проверь доступность сайта и RLS-политики.
